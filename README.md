# 🍽️ مطعم السلام — منصة طلب طعام أونلاين

**مشروع ويب متكامل (Full-Stack)** | PHP · MySQL · JavaScript

---

## 📌 نظرة عامة

منصة كاملة لطلب الطعام أونلاين، صمّمتها وطوّرتها من الصفر باستخدام **PHP + MySQL**، تغطي رحلة الزبون كاملة من تصفح القائمة إلى تأكيد الطلب، بالإضافة إلى لوحة تحكم إدارية لمتابعة العمليات اليومية للمطعم.

المشروع مبني بثيم بصري مستوحى من **"تذكرة الطلب"** (Order Ticket)، ويطبّق ممارسات أمنية أساسية مثل الاستعلامات المحضّرة (Prepared Statements) وتشفير كلمات المرور بـ bcrypt.

---

## ✨ الميزات الرئيسية

### واجهة الزبون
- تصفح القائمة مصنّفة حسب الأصناف
- إضافة الأطباق إلى السلة عبر AJAX دون إعادة تحميل الصفحة
- تعديل السلة (زيادة/إنقاص/حذف) بشكل تفاعلي
- إتمام الطلب مع تعبئة معلومات التوصيل
- صفحة تأكيد/إيصال بعد إرسال الطلب

### لوحة الإدارة
- تسجيل دخول آمن للمدراء
- متابعة الطلبات الواردة وتغيير حالتها لحظيًا
- إضافة / تعديل / حذف الأطباق من القائمة
- تفعيل أو تعطيل توفر أي طبق
- لوحة إحصائيات سريعة للطلبات

## 🏗️ البنية التقنية

```
alsalam/
├── config.php              # اتصال قاعدة البيانات + كشف البيئة تلقائيًا
├── database.sql            # المخطط الكامل + بيانات تجريبية (5 أصناف، 12 طبق)
├── index.php                 # الصفحة الرئيسية
├── menu.php                   # القائمة الكاملة + إضافة للسلة
├── cart.php                   # عرض السلة وتعديلها
├── cart_action.php           # نقطة AJAX لإضافة/تعديل/حذف عناصر السلة
├── checkout.php               # نموذج بيانات التوصيل + تسجيل الطلب
├── order_success.php         # إيصال تأكيد الطلب
├── includes/
│   ├── header.php / footer.php
│   └── functions.php
├── assets/
│   ├── css/style.css         # كل التصميم (ثيم "تذكرة الطلب")
│   └── js/script.js
└── admin/
    ├── login.php / logout.php
    ├── dashboard.php          # الطلبات + الإحصائيات + تغيير الحالة
    ├── menu.php                # قائمة الأطباق + تفعيل/تعطيل
    ├── menu_form.php           # إضافة/تعديل طبق
    └── delete_item.php
```

**التقنيات المستخدمة:** PHP · MySQL · JavaScript (AJAX) · HTML/CSS

## 🔒 جوانب الأمان المطبّقة

| الممارسة | التطبيق |
|---|---|
| منع SQL Injection | استعلامات محضّرة (Prepared Statements) في كل الاستعلامات |
| تشفير كلمات المرور | bcrypt عبر `password_hash()` |
| حماية الأسعار | إعادة التحقق من السعر من قاعدة البيانات عند الدفع، دون الاعتماد على أي سعر قادم من المتصفح |
| بيانات الاتصال | فصل إعدادات البيئة المحلية عن إعدادات الاستضافة داخل `config.php` |

---

## 🚀 النشر

- **محليًا:** عبر XAMPP/MAMP/WAMP، مع استيراد `database.sql` وضبط `config.php`.
- **على الاستضافة:** تم رفع المشروع بنفس منهجية النشر المستخدمة سابقًا في مشروع `gestionlesall`، عبر إنشاء قاعدة بيانات MySQL على لوحة تحكم الاستضافة (cPanel)، ثم رفع الملفات عبر File Manager أو FTP.
