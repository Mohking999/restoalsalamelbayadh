# موقع طلبات مطعم السلام 🍽️

موقع كامل لطلب الطعام أونلاين، مبني بـ PHP + MySQL، يتضمن:
- واجهة زبون: تصفح القائمة حسب الصنف، إضافة للسلة، إتمام الطلب بمعلومات التوصيل.
- لوحة إدارة: متابعة الطلبات وتغيير حالتها، إضافة/تعديل/حذف الأطباق، تفعيل أو تعطيل التوفر.

---

## 1) التشغيل محليًا (XAMPP / MAMP / WAMP)

1. انسخ مجلد `alsalam` بالكامل إلى `htdocs` (أو المجلد المكافئ في MAMP/WAMP).
2. افتح phpMyAdmin وأنشئ قاعدة بيانات باسم `alsalam_restaurant` (utf8mb4).
3. استورد ملف `database.sql` إلى هذه القاعدة (تبويب Import في phpMyAdmin، أو الأمر: `mysql -u root alsalam_restaurant < database.sql`).
4. تأكد أن إعدادات `config.php` في القسم الخاص بـ localhost صحيحة (افتراضيًا: user=root, password فارغة).
5. افتح المتصفح على: `http://localhost/alsalam/index.php`

**حساب الإدارة التجريبي:** `admin` / `alsalam2026` — **غيّر كلمة المرور فورًا** بعد أول دخول (أنشئ حساب إدارة جديد من قاعدة البيانات مباشرة عبر `password_hash()`، ثم احذف الحساب التجريبي).

---

## 2) الرفع على استضافة (مثال: ezyro.com)

نفس الخطوات التي استعملتها سابقًا في مشروع `gestionlesall`:

1. من لوحة تحكم الاستضافة (cPanel)، أنشئ قاعدة بيانات MySQL جديدة ومستخدمًا مرتبطًا بها، واحتفظ بـ:
   - اسم القاعدة (مثال: `ezyroXXXXXX_alsalam`)
   - اسم المستخدم وكلمة المرور
   - عنوان خادم القاعدة (غالبًا `sql.ezyro.com` أو مشابه)
2. افتح `config.php` وعدّل قسم "إعدادات الاستضافة" بهذه المعلومات الأربع.
3. من phpMyAdmin الخاص بالاستضافة، استورد `database.sql`.
4. ارفع كل ملفات المجلد `alsalam/` عبر File Manager أو FTP إلى `public_html` (أو `htdocs` حسب الاستضافة).
5. تأكد من صلاحيات المجلدات عادية (755) والملفات (644)، ولا حاجة لأي إعداد إضافي لأن الموقع لا يكتب ملفات على القرص.
6. جرّب الموقع عبر رابط النطاق، مثال: `https://www.mystyle.dz` أو النطاق الذي اخترته لمطعم السلام.

⚠️ **مهم:** لا ترفع أبدًا كلمة مرور قاعدة البيانات الحقيقية إلى مستودع Git عام. إذا استعملت Git، أضف قاعدة استثناء أو خزّن بيانات الاتصال في متغيرات بيئة بدل كتابتها مباشرة في `config.php` عند الإمكان.

## 3) البنية

```
alsalam/
├── config.php              # اتصال قاعدة البيانات + كشف البيئة تلقائيًا
├── database.sql            # المخطط الكامل + بيانات تجريبية (5 أصناف، 12 طبق)
├── index.php                # الصفحة الرئيسية
├── menu.php                  # القائمة الكاملة + إضافة للسلة
├── cart.php                  # عرض السلة وتعديلها
├── cart_action.php          # نقطة AJAX لإضافة/تعديل/حذف عناصر السلة
├── checkout.php              # نموذج بيانات التوصيل + تسجيل الطلب
├── order_success.php        # إيصال تأكيد الطلب
├── includes/
│   ├── header.php / footer.php
│   └── functions.php
├── assets/
│   ├── css/style.css        # كل التصميم (ثيم "تذكرة الطلب")
│   └── js/script.js
└── admin/
    ├── login.php / logout.php
    ├── dashboard.php         # الطلبات + الإحصائيات + تغيير الحالة
    ├── menu.php               # قائمة الأطباق + تفعيل/تعطيل
    ├── menu_form.php          # إضافة/تعديل طبق
    ├── delete_item.php
    └── includes/header.php / footer.php
```

---

## 4) نقاط مهمة للأمان قبل الإطلاق الفعلي

- غيّر كلمة مرور حساب الإدارة التجريبي فورًا.
- تأكد أن `config.php` لا يحتوي على كلمة مرور حقيقية إذا كان المستودع عامًا على GitHub.
- الأسعار يُعاد التحقق منها من قاعدة البيانات عند الدفع (لا يُعتمد على أي سعر قادم من المتصفح) — هذا مطبق بالفعل في `checkout.php`.
- كل الاستعلامات تستعمل Prepared Statements لمنع SQL Injection.
- كلمات المرور مخزّنة بتشفير bcrypt عبر `password_hash()`.

## 5) أفكار للتطوير لاحقًا

- إشعار واتساب/SMS تلقائي عند استلام طلب جديد.
- صور حقيقية للأطباق (استبدال شارات الألوان الحالية).
- صفحة "تتبع طلبي" عبر رمز الطلب للزبون.
- دعم الدفع الإلكتروني أو الدفع عند الاستلام كخيارين واضحين في الطلب.
